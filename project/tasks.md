# 작업 목록 (tasks.md)

- [x] 게임 기획 명세서 작성 (`spec.md`)
  - **Live Server 확인 내용**: 없음 (기획 문서 작성 완료)

- [x] 1. 프로젝트 뼈대 및 Phaser 3 세팅
  - **작업 내용**: CDN을 통한 Phaser 3 로드, 모바일 세로 비율(480×800) 게임 캔버스 설정, 모듈형 JS 구조 세팅 (`index.html`, `src/main.js`, `src/scenes/GameScene.js`)
  - **Live Server 확인 내용**: 브라우저 콘솔 에러 없이 화면 중앙에 480×800 크기의 게임 영역이 정상적으로 렌더링되는지 확인.

- [x] 2. 플레이어 기본 이동 (키보드 조작)
  - **작업 내용**: 플레이어 엔티티 생성(도형 형태), 키보드 방향키 및 WASD 입력을 통한 4방향/8방향 이동 구현
  - **Live Server 확인 내용**: 화면 중앙에 생성된 플레이어가 방향키/WASD 입력에 맞춰 부드럽게 이동하는지 확인.

- [x] 3. 플레이어 화면 경계 제한 및 터치(가상 드래그) 이동 지원
  - **작업 내용**: 플레이어가 480×800 화면 경계 밖으로 벗어나지 않도록 물리 경계 설정, 마우스/터치 드래그로도 이동할 수 있도록 포인터 이동 처리 추가
  - **Live Server 확인 내용**: 화면 끝으로 이동 시 플레이어가 캔버스 밖으로 나가지 않는지, 마우스 드래그 또는 터치로 이동 방향을 조작할 수 있는지 확인.

- [x] 4. 자동 공전 궤도 무기 (회전 위성) 기본 구현
  - **작업 내용**: 플레이어 몸 주위를 일정한 반지름과 속도로 자동 회전하는 궤도 무기 1개 생성 및 공전 로직 구현
  - **Live Server 확인 내용**: 플레이어가 정지해 있거나 이동할 때도 무기가 플레이어 중심을 기준으로 원형 궤도를 일정 속도로 계속 회전하는지 확인.

- [x] 5. 기본 적(Enemy) 생성 및 플레이어 추적 이동
  - **작업 내용**: 화면 외곽에서 일정 간격마다 적 도형 스폰, 생성된 적이 플레이어의 현재 위치를 향해 지속적으로 추적 이동하도록 구현
  - **Live Server 확인 내용**: 화면 가장자리에서 적들이 주기적으로 생성되어 플레이어를 향해 다가오는지 확인.

- [x] 6. 궤도 무기와 적의 피격 및 처치 판정
  - **작업 내용**: 회전하는 무기와 적 간의 충돌 검사, 적 피격 시 깜빡임(플래시) 효과, 적 체력 소진 시 제거 처리
  - **Live Server 확인 내용**: 회전하는 무기가 적과 닿으면 적이 깜빡이며 피해를 입고, 일정 횟수 타격 시 적이 정상적으로 소멸하는지 확인.

- [x] 7. 경험치 보석 드랍 및 플레이어 습득
  - **작업 내용**: 적 사망 위치에 경험치 젬(작은 보석 도형) 생성, 플레이어가 젬에 닿았을 때 습득 및 소멸 처리
  - **Live Server 확인 내용**: 적이 죽은 자리에 보석이 떨어지고, 플레이어가 다가가 닿으면 보석이 사라지는지 확인.

- [x] 8. 상단 HUD UI (생존 타이머, 플레이어 체력 바, 경험치 바)
  - **작업 내용**: 화면 상단에 생존 시간 타이머(00:00), 플레이어 HP 바, 경험치 게이지 바 UI 표시
  - **Live Server 확인 내용**: 초 단위 타이머가 정상 증가하고, HP 바와 경험치 젬 습득 시 EXP 바가 차오르는지 확인.

- [x] 9. 플레이어 피격 판정 및 무적 시간
  - **작업 내용**: 적이 플레이어와 접촉했을 때 플레이어 HP 감소 및 피격 무적 시간(피격 시 깜빡임) 처리
  - **Live Server 확인 내용**: 적과 닿았을 때 플레이어 체력 바가 줄어들고, 플레이어가 깜빡이며 연속 피해를 즉시 받지 않는 무적 시간이 적용되는지 확인.

- [x] 10. 레벨업 판정 및 3택 스킬 선택 팝업 UI
  - **작업 내용**: 경험치 바 완충 시 레벨업 처리, 게임 일시정지, 무기/패시브 강화 3종 선택지 팝업창 출력
  - **Live Server 확인 내용**: 경험치가 다 차면 게임이 멈추고 3가지 강화 선택 카드 팝업이 뜨는지 확인.

- [x] 11. 스킬 강화 효과 적용 및 게임 재개
  - **작업 내용**: 팝업에서 카드 선택 시 해당 능력(무기 개수 +1, 무기 회전 속도 증가, 플레이어 이동 속도 증가 중 택 1) 적용 후 팝업 닫힘 및 게임 재개
  - **Live Server 확인 내용**: 선택한 강화 효과가 즉시 인게임에 반영(예: 궤도 무기가 2개로 늘어나거나 빨라짐)되고 게임이 다시 정상 진행되는지 확인.

- [x] 12. 시간 경과에 따른 웨이브 강화 및 보스 몬스터 등장
  - **작업 내용**: 타이머 시간에 따라 적 스폰 주기 및 적 스펙 증가, 정해진 시간(예: 3분, 테스트 시 단축 가능) 도달 시 대형 보스 몬스터 출현
  - **Live Server 확인 내용**: 시간이 지날수록 적이 더 많이/빠르게 나오며, 목표 시간에 큰 보스 몬스터가 체력바를 가지고 등장하는지 확인.

- [x] 13. 게임 오버(실패) 판정 및 재도전 처리
  - **작업 내용**: 플레이어 HP가 0이 되었을 때 게임 일시정지, 게임 오버 화면 및 생존 시간 표시, 재시작(Retry) 버튼 구현
  - **Live Server 확인 내용**: 체력이 다 닳으면 GAME OVER 팝업이 뜨고, 재시작 버튼을 누르면 초기 상태로 씬이 깔끔하게 재시작되는지 확인.

- [x] 14. 보스 처치(성공) 판정 및 게임 클리어 처리
  - **작업 내용**: 보스 몬스터 처치 시 게임 클리어 화면 및 클리어 시간 표시, 재시작 버튼 구현
  - **Live Server 확인 내용**: 보스를 물리치면 VICTORY / CLEAR 화면이 나타나고 재시작 버튼을 통해 게임을 다시 시작할 수 있는지 확인.
